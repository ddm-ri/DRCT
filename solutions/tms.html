Frequently Asked Questions

  • How does NDC integration for a travel management system work through DRCT?

    DRCT acts as an orchestration layer between airline inventory sources and your TMS. You connect once to the DRCT API or use the embedded interface, and DRCT handles connections to individual airlines — GDS, NDC direct APIs, and custom integrations. Offers are normalized into a consistent data structure before they reach your platform, so your system never has to handle airline-specific formatting or schema changes.

  • What is included in NDC order management via DRCT?

    DRCT's order management layer covers the full post-booking lifecycle for NDC orders: seat changes, name corrections, voluntary and involuntary cancellations, refunds, and reissuance. Standard actions are available via API for self-service integration. Complex cases — including airline-specific workflows and settlement disputes — are handled by DRCT's operations team, available 24/7.

  • Can DRCT work alongside an existing GDS connection?

    Yes. DRCT is designed to complement, not replace, existing GDS connections. Your TMS can continue using GDS for traditional content while DRCT adds NDC, direct airline, and low-cost carrier inventory in parallel. Offers from all sources are normalized, so your platform receives a consistent data structure regardless of the booking channel.

  • How does DRCT support accounting and reporting for NDC bookings?

    DRCT provides structured transaction data for all bookings — including NDC — in a format compatible with standard back-office systems. This covers booking records, fare breakdowns, ancillary line items, and settlement data. For TMCs with BSP reporting requirements, DRCT includes support for reconciliation workflows that handle NDC alongside traditional GDS transactions.

  • What happens when an airline updates its NDC API?

    DRCT absorbs airline-side API changes before they reach your TMS. When an airline updates its NDC spec, changes session behavior, or modifies its error handling, DRCT's team updates the integration — your system continues to receive a stable, normalized data structure with no breaking changes on your end. This applies to schema changes, certification updates, and new feature rollouts.

  • How long does integration with DRCT typically take?

    Integration timelines depend on your TMS architecture and the depth of the integration. API-based integrations typically complete in a matter of weeks rather than months. The embedded DRCT BT for TMS interface can often be deployed faster, since it doesn't require custom booking UI development. DRCT provides technical documentation, sandbox access, and dedicated integration support throughout the process.
