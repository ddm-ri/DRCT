Built for developers

Straightforward integration, comprehensive documentation, and production-ready APIs.

Single API endpoint

One integration covers 40+ airlines. No per-airline SDKs, no separate credentials per carrier. DRCT normalises differences across NDC implementations so you don't have to.

REST architecture

Standard JSON over HTTPS. Compatible with any language or framework. Full OpenAPI spec available — import into your favourite HTTP client and start testing in minutes.

Sandbox environment

Full sandbox with simulated airline responses. Test search, booking, ticketing, and post-sales without live transactions. Sandbox credentials provided with API access.

GDS-compatible commands

DRCT API accepts GDS-style fare entry commands (FQD-style). Integrate alongside existing GDS workflows — your agents see NDC fares in the same format they already know.

Webhooks and queues

Receive real-time notifications for booking changes, schedule disruptions, and queue events. Configure webhook endpoints in your DRCT developer account for any booking lifecycle event.

Full documentation

FAQ

If you didn't find an answer to your question, please reach out to our developer support.

  • How do I get API access?

    Request access through this page. Our team will provide sandbox credentials within 24–48 hours. Production access follows once your integration testing is complete and reviewed.

  • Is there a sandbox environment?

    Yes. All API partners receive full sandbox access with simulated airline responses. You can test search, booking, ticketing, and post-sales endpoints without live transactions or billing.

  • Which authentication method does the API use?

    The DRCT API uses API key authentication passed via request header. Full authentication documentation, including request signing and token refresh flows, is available at developers.drct.aero.

  • Which airlines are available through the API?

    The API provides access to all 40+ airlines connected to DRCT, including Lufthansa, British Airways, Emirates, American Airlines, Iberia, SWISS, TAP, LOT, and more. The full live list is available at developers.drct.aero.

  • Which GDS platforms are supported?

    DRCT integrates with Amadeus, Sabre, and Galileo/Travelport. You can use the API independently or as part of a GDS-integrated workflow — both approaches are fully supported.

  • Are webhooks available for booking events?

    Yes. DRCT provides webhooks for booking status changes, schedule disruptions, and queue notifications. Configure webhook endpoints in your DRCT developer account for any booking lifecycle event.

  • Where is the API documentation?

    Full API reference, integration guides, and OpenAPI spec are available at developers.drct.aero. The documentation covers all endpoints, request/response formats, and error codes.

  • What is the pricing model?

    DRCT collects a fixed service fee only when a booking is ticketed — no subscription, no monthly fee, no per-search charge. Contact us for volume pricing on high-traffic implementations.
