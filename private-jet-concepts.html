Private Jet Integration — 3 UX Concepts
Concept explorations for embedding private jet alternatives inside the commercial flight search results page. Each concept takes a different stance on hierarchy, emotional tone, and interaction complexity. All concepts stay within the DRCT design language and do not redesign the surrounding UI.
1
Concept
The Elevated Divider
A dedicated premium section inserted between commercial results, separated by a gold-ruled header bar. Jets appear on a horizontal scroll rail — visually a tier above regular results, but spatially embedded in the page flow. The framing is quiet and editorial: no banners, no gradients — just a thin gold accent line and restrained type saying "Private alternatives available." The rail format lets agents scan multiple jet categories at once without losing their place in the regular results above.
Hierarchy
Gold top-border signals tier change. PRIVATE ALTERNATIVES label in uppercase gold reads as a section heading, not an ad. Regular flight rows continue below — hierarchy is spatial, not modal.
Emotional position
Feels like a concierge note tucked inside a dossier. The warm sand background of the rail creates thermal contrast from the white page — premium without being loud. Think Amex Centurion insert, not an upsell banner.
Interaction
Rail scrolls horizontally. Click on a card expands it slightly (scale 1.01, shadow lift). Request CTA is always visible at card bottom — no hover reveal. Works on desktop + mobile via touch scroll.

2
Concept
The Ambient Takeover
A full-width editorial interstitial block inserted between results — not a rail, not cards on a shelf. It presents jet options as a curated recommendation. The agent sees a quiet gold left-border accent, an eyebrow ("Fly privately"), a short curatorial headline, and then 2–3 option tiles laid side by side. One tile is pre-selected (the most relevant category for the searched route). The block reads as a considered recommendation from the platform, not a marketplace listing. CTA is restrained: "Request selected" — singular, decisive.
Hierarchy
Eyebrow → headline → sub → option tiles → CTA. Linear reading, zero ambiguity. The pre-selected tile collapses decision friction — agent needs one click to proceed.
Emotional position
Concierge recommendation. "Here's what we'd suggest for this route." Warm parchment tones on the selected tile. The adjacent image panel reinforces the premium category without needing photography.
Interaction
Click a tile to select it (check appears, tile warms). Click "Request selected" → Option A modal or Option B instant send. Tiles don't expand — details are surfaced inline. Dismissible via text link at bottom.

3
Concept
The Contextual Thread
Jet options appear as rows directly threaded into the results list — structurally parallel to commercial flight rows, but unmistakably different in visual register. A thin golden divider row separates the commercial results above from the jet rows below, reading as "same list, elevated tier." Each jet row follows the same left-to-right data rhythm as flight rows (category, models, capacity, route, price, CTA) — agents who know how to read flight rows instantly know how to read jet rows. No new learning required. Differentiation is achieved through the gold left-border accent, warm price pill, and restrained typographic treatment.
Hierarchy
Minimal hierarchy disruption. Jets sit in the same flow as flights. The gold left-border and divider label are the only premium signals needed. Agents who scan rows quickly won't miss the tier change.
Emotional position
Efficiency over aspiration. This concept suits the professional travel agent context — someone scanning results fast, not being seduced. Premium is signaled through restraint, not surface area.
Interaction
Row click expands inline (accordion) showing more detail — models list, carousel placeholder, baggage note with tooltip. Collapsed by default for speed. CTA always visible in the row's right column.

Mobile responsiveness — all 3 concepts
Concept 1 (Rail): Rail becomes a horizontally swipeable strip on mobile. Cards reduce to 200px wide. Section header collapses to icon + label only. Works naturally with touch.

Concept 2 (Ambient block): Image aside hides on mobile (below 768px). Options stack vertically. CTA row becomes full-width stack. Still readable and actionable in one thumb reach.

Concept 3 (Threaded rows): On mobile, rows collapse to a stacked card layout (category + price + CTA visible, rest hidden behind expand). Gold left-border becomes a top-border to signal premium tier in a card-stack layout. The threaded concept requires most adaptation on mobile but retains the speed of scanning.
!
Edge cases
Empty states + API failures
Two meaningful edge cases require explicit handling. Neither should degrade the commercial results experience.
Case 1 — No jets available for this route
Recommendation: Silent omission. Do not render the private jet section at all. No "No jets found" placeholder — that creates visual noise and draws attention to a gap. The agent simply sees commercial results as normal. This is the cleanest UX for a B2B tool. Optionally: log the route in analytics as a "jet interest signal" for business development purposes without surfacing it to the user.
Case 2 — JetsBetter API timeout or error
Recommendation: Silent fail + internal logging. If the API call doesn't resolve within a reasonable timeout (suggested: 3 000ms), suppress the jet section entirely. Do not show a spinner that never resolves. Do not show a broken state. Log the failure to Sentry with context: 'jets_api_timeout', route details, and timestamp. Optionally trigger an internal Slack/Telegram alert if error rate exceeds a threshold (e.g., 5 failures in 10 minutes). The agent experience is unaffected — they see clean commercial results.

Optional degrade: If partial data is available (e.g., categories list loaded but prices failed), show the section with "Prices on request" instead of amounts. Button label changes to "Request for quote." This preserves the discovery moment while being honest about data availability.
